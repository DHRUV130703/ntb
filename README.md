# NOT TO BRAG® — nottobrag.app

Website for NOT TO BRAG, a creative, marketing and technology agency in Mumbai.
React (Vite) frontend, Node/Express backend for the contact form.

```bash
npm install
npm run dev        # http://localhost:5173 (API on :8787)
npm test -w server
npm run build
```
